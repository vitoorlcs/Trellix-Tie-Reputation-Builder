# Trellix-Tie-Reputation-Builder
A portable single-page web tool for building Trellix TIE reputation import XML files. It supports manual entry, CSV import, hash normalization, reputation assignment, validation, live XML preview, clipboard copy, and XML download in a cyber-themed local interface.
